# 주문형 URL 수집 요청 — 이 파일을 고쳐 push 하면 .github/workflows/collect-fetch.yml 이 돈다.
# 결과: intake/files/fetch/{날짜}/{label}.{ext} + intake/collected.jsonl 한 줄(routed:false).
# 형식: label | https://url   (label 생략 가능 · '#' 주석 · https 만)
# 왜 있나: 세션 샌드박스의 egress 정책에 막힌 호스트를 사용자 소유 CI 러너에서 받기 위해서다(§W5 · §H1).
#   프록시 우회가 아니다 — 세션의 403 은 조직 정책이고 여기서 쓰는 건 시세 봇이 쓰는 것과 같은 길이다.
# 📌 근본 해결은 환경 allowlist 다(사용자 결정 2026-09-20) — 목록·경로는 docs/method_datasource.md 맨 뒤.
#   allowlist 가 적용되면 반복 구조화 출처(SEC·네이버·DART·FRED)는 세션에서 바로 읽고,
#   이 파일은 allowlist 에 넣을 수 없는 일회성 페이지(언론 기사·정부 발표 첨부)만 남는다.
# 처리 끝난 요청은 지운다(git 이 기억한다). 지우지 않으면 다음 push 때 또 받아 id 만 늘어난다.
