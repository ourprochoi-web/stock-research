### 한줄 핵심(사실)
김아람 이사는 구글이 10월 13일(화) 유료 구독자에게 연 새 모델 '제미나이 아르곤'이 아레나·Vals 리더보드 1위를 차지했지만 코딩(아레나 웹개발 8위)·토큰 사용량(경쟁 모델 2~3배)·과잉 추론 문제로 평가가 갈린다고 전했고, 메타는 하루 앞서 최상위 '뮤즈 원더' 계열을 유료·폐쇄형으로 내놓아 라마 오픈소스 노선에서 '최상위 유료 + 별도 공개모델' 이중 전략으로 바뀌었다고 설명했다.

### 상세 요약
**(1) 배경 — 두 달 전 "구글 위기론"**
- 8월 초 같은 코너에서 김덕진 소장이 데미스 허사비스(딥마인드)의 일상 경영 후퇴, 핵심 인력 이탈, 신모델 지연, 제미나이가 답을 짧게 하고 검색을 덜 해 "토큰을 아낀다"는 사용자 원성 → "구글이 민심을 잃고 있다"고 소개했었음.

**(2) 아르곤 공개 경과**
- **9월 30일** 발표 당시 "당분간 신뢰할 수 있는 사이버보안 전문가에게만 공개" — 구글 보안 협력 프로그램 **페어윈드** 소속 보안 회사·연구자에게만 개방.
- 이유: 아르곤은 소프트웨어 보안 허점을 스스로 찾아 진위를 확인하고 고치도록 학습된 모델. 구글 설명으로 **모의 사이버공격 시나리오 12개 전부 해결**(이전 모델 **5개**). 악용 시 해킹 도구가 될 수 있어 방어 측에 먼저 제공.
- **블룸버그** 보도: 구글 직원 일부가 실제 코딩, 특히 **프런트엔드** 작업에서 벤치마크만큼 성능이 안 나온다고 말했다는 내용 → "벤치맥싱"(시험 유형에 맞춘 점수 올리기) 의심. 구글은 "코딩 성능이 떨어진다는 말은 부정확하다"고 반박.
- **10월 13일(화)** 유료 구독자에게 공개(발표 후 약 2주). 초기 불만: 월 **20달러** 구독자 앱에서 모델이 안 보여 "**100달러 넘는 울트라 전용 아니냐**" 논란 → 구글은 "수요가 커 용량을 늘리며 점진적으로 배포 중"이라고 발표. 첫 반응은 좋지 않았다는 평가.
- 성적: **아레나**(사람이 직접 비교 투표하는 리더보드) **종합 1위**, **Vals**(금융·법률·코딩 과제 평가) **1위** — Vals에서 구글 모델 1위는 **이번이 처음**.

**(3) 아르곤 호평 — "문과 대만족"**
- 글쓰기·설명: 클로드에 하던 질문을 아르곤에 했더니 요점 중심·논리 구조가 잘 짜인 "잘 쓴 짧은 에세이 같다"는 반응. 아레나 **지시 이행 항목 1위**.
- 번역: 국내 커뮤니티 후기 — 외국어 소설을 한국어로 번역시키니 인물 성격에 맞게 말투가 바뀌고 비속어·인터넷 용어까지 살리며 이유도 설명. "웹소설 플랫폼에 올려도 구분 못 할 것"이라는 댓글.
- 환각: 독립 평가기관(Artificial Analysis로 추정) 측정 환각률 **15%** vs 오픈AI 최신 모델 **50%대**. 다만 정답률 자체는 아르곤 **50%**, 오픈AI 모델 **63%** — 모르는 질문에 "모른다"고 답하는 비중이 늘어 아는 척을 덜 한다는 의미.
- 에이전트 작업: 한 개발자가 파일 **1,200개 넘는 서버**를 맡겼더니 도구를 **150~300회** 호출하며 혼자 작업하고 보안 구멍을 많이 찾아줬다는 후기 → 보안 전문가 선공개 이유로 해석.
- 진행자 코멘트: 머스크가 그록을 "제조에 적합한 최고의 AI가 될 가능성"이라고 평가, 클로드는 코딩에서 압도적 평가, 제미나이는 "문과 대만족".

**(4) 아르곤 불만 — 코딩·한도·과잉 사고**
- 코딩: 아레나 종합 1위지만 **코딩/웹개발 부문 8위**. 한국 개발자 후기 중론 "오퍼스(앤트로픽 클로드 상위 모델)에 못 미친다", 게임 개발자들 사이 "그냥 오퍼스 써라".
- 한도: 8월엔 "토큰 아낀다"가 불만이었는데 아르곤은 정반대 — 같은 과제에 출력 토큰이 경쟁 모델의 **약 2~3배**. 커뮤니티: 이전 버전은 같은 질문에 한도 **1%** 사용, 아르곤은 "안녕"만 해도 **5%**씩 소진(ASR 「안영만」). 구글 개발자 포럼에 "이럴 거면 쓸 이유 없다, 해지하고 경쟁사로 가야겠다", "집단 해지밖에 답이 없다"는 비판. "토큰 아끼던 제미나이가 두 달 만에 토큰 먹는 제미나이로 돌아왔다."
- 과잉 추론: "이 설정 빨리 확인만 해 줘, 퀵"이라고 지시했는데 **25분** 혼자 돌다 다운된 사례 등 "무한 추론 루프" 보고.
- 벤치마크 조건 논란: 구글 발표 점수는 **하이 모드**(가장 깊게 생각) 기준인데 앱 기본값은 **미디엄** → 점수와 체감 차이. 환각 "역대 최저" 수치에도 "첫 질문부터 환각"이라는 사용자도 있음.

**(5) 사용자 선택(김아람 이사 의견)**
- 국내 이용자(와이즈앱·리테일 집계로 추정, 9월): **챗GPT 앱 2,470만 명**, **제미나이 987만 명**(챗GPT의 약 40%). 제미나이는 7~9월 **약 40만 명** 증가에 그쳐 증가폭 크지 않음. "써 봤는데 글쎄" 반응 누적 — 발표마다 1등이라 하지만 써 보면 다르다는 경험. 200달러 플랜을 한 번이라도 써 본 사람은 "한 달 무료면 생각해 볼게" 수준.
- 글쓰기·번역·자료정리·보고서 초안 업무라면 써 볼 만함: 개발자용 **API 가격 반값 할인이 11월 30일까지**, **12월부터 가격 복구**. 코딩이 주 업무이거나 질문을 매우 자주 하는 사용자는 "아직" — 코딩은 클로드가 위라는 평가, 한도가 빨리 소진. 요약: "코딩과 한도가 중요하면 아직, 글 작업이 많으면 갈아탈 만하다."

**(6) 메타 '뮤즈 원더' — 구글 발표 하루 전 공개**
- 앞서 '뮤즈' 에이전트 발표에 이어 구글 발표 **하루 전** 「뮤즈 원더」 공개, 메타는 "에이전트를 위한 프런티어 모델, 역대 가장 강력한 모델"이라 소개. "경쟁사를 따라잡았다"는 취지의 보도.
- Artificial Analysis(추정) 종합 지수: **클로드 오퍼스 5.5 58점(1위)**, 메타 상위 모델(ASR 「뮤즈 원더 풀」) **56점**(2점 차 2위권), **구글 아르곤 53점**.
- 강점: 긴 작업을 혼자 처리하는 에이전트 능력, 여러 번 대화해도 사용자를 기억하는 메모리. 약점: 창작 글쓰기가 건조, 3D·영상 약함.
- 모델 두 개: 「뮤즈 원더」와 상위 「뮤즈 원더 풀」(ASR). 성적 좋은 상위 모델은 **유료 구독자 전용**, 개발자 **API로는 하위 「원더」만 개방**.

**(7) 메타의 노선 전환 — 오픈소스 → 이중 전략**
- 저커버그는 2~3년 전 "오픈소스 AI가 미래로 가는 길"이라고 말함. **라마 누적 다운로드 작년 4월 기준 12억 회 이상**, 수천 개 회사가 라마 기반 서비스 개발.
- **작년 4월 라마 4** 출시 → 평가 저조, 리더보드 제출 버전과 공개 버전이 달랐던 것이 드러나 논란("시험장엔 과외 받은 학생, 고객에겐 일반 학생").
- **작년 6월** 인재 영입 전쟁, **스케일AI에 143억 달러(약 20조 원)** 투자 후 창업자 **알렉산더 왕** 영입, 초지능 연구 조직 신설, 기존 연구소 인력 **약 600명** 내보냄.
- **작년 12월** 차기 모델을 판매용 폐쇄형으로 만든다는 보도 → **올해 4월** 폐쇄 모델 「뮤즈 스파크」 출시, 최상위 모델 폐쇄형 제공.
- 공개 모델 유지: **15일** **8,160억 파라미터** 공개 모델 「뮤즈 스파크 오픈」 공개 → 최상위는 구독, 별도 공개 모델은 무료인 **이중 전략**.
- 이유 ①돈: 메타의 올해 AI 설비 투자 **약 180조~200조 원**, 작년의 **거의 2배**. **2분기 실적** 잉여현금흐름 전년 대비 **−91%**. 저커버그가 팟캐스트에서 알렉산더 왕에게 거액 수표(ASR 「1억 2,000달러짜리」, 금액 판독 불확실)를 쓰며 "이거 정말 되는 거냐" 물었고, 왕은 재무책임자가 여러 번 불러 "실패하면 정말 큰일"이라고 했다는 일화. 공개 모델만으로는 직접 수익화가 어려워 최상위 모델은 유료 구독·API로 돈을 버는 전략.
- 이유 ②중국: 메타 오픈소스 목표는 "전 세계 AI의 기본 재료"가 되는 것이었는데 그 자리를 중국이 가져감. 작년 초 딥시크, 이후 알리바바 Qwen이 다운로드 수에서 라마 추월. 오픈라우터 등 중계 서비스에서 중국계 공개 모델 사용 비중 급증, 허깅페이스에서 Qwen 기반 파생 모델 급증. **a16z 파트너** 인터뷰: 오픈소스로 사업하겠다는 스타트업 **80% 이상이 중국 모델 기반**. → "돈은 돈대로 쓰고 생태계는 중국에 뺏기고 성능도 1등이 아닌" 상황에서 방향 전환.

**(8) 한국·기업 영향**
- 비유: 오픈소스 모델 = 공공 상수도, 폐쇄형 = 생수 배달(품질은 좋을 수 있으나 비용 높고 가격 인상 시 영업 곤란). 라마 기반 수천 개 회사는 라마 발전이 멈추면 대안 필요.
- **중국 상무부 AI 모델 수출통제 초안**(며칠 전 공개, 보도 기준): 파라미터 **2조 개 이상**이거나 성능이 세계 최상위권이면 가중치·소스코드·설계 구조를 허가 없이 해외 이전 금지. 의견 수렴 **11월 15일까지**, **사전 등록 의무는 16일부터 즉시 시행**. → 오픈소스 선택 시 미국/중국 모델 선택이 사업 안정성에 큰 요소.
