마이크로소프트가 엔비디아 칩 기반 미니 PC ‘서피스 RTX 스파크 데브 박스’를 공개. 가격은 5,999달러로 책정됐으며 이날부터 사전 주문 시작.

개발자를 주요 대상으로 설계됐으며 AI 모델을 기기에서 직접 구동하도록 최적화. 1,200억 개 이상의 매개변수를 가진 대규모 언어모델을 지원하며, AI 모델 테스트와 AI 에이전트 프로토타이핑, AI 기반 코딩 도구 실행 등에 활용 가능.

엔비디아 RTX 스파크 플랫폼을 탑재해 Arm CPU 코어 20개와 CUDA 코어 6,144개를 갖춘 블랙웰 GPU 제공. 통합 메모리 128GB와 2TB SSD 탑재.

더버지에 따르면 TDP는 100W이며, 3D 프린팅 방식의 아노다이징 알루미늄 케이스가 냉각용 방열판 역할을 동시에 수행. 외형은 엑스박스 시리즈 X 상단 환기구와 유사한 형태.

마이크로소프트의 ‘프로젝트 제니스’에 포함된 제품으로 개발자용으로 최적화된 윈도우 11 프로와 비주얼 스튜디오 코드, Git, GitHub CLI, GitHub Copilot, WSL, Python, Node 등이 기본 설치.

출하는 11월 시작 예정. 가격은 5,999달러로 지난해 엔비디아가 출시한 DGX 스파크 미니 PC보다 높은 수준이며, RAM을 비롯한 부품 공급 부족으로 컴퓨터 가격이 상승하는 상황.
