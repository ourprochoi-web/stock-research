앤스로픽, AI 에이전트 확산에 대응해 자체 소스 코드 관리 시스템 구축

: 앤스로픽의 하루 코드 병합 건수는 5월 약 2,500건에서 9월 30,000건 이상으로 12배 증가. Claude의 코딩 생산성이 급증하면서 코드 작성보다 소스 코드 관리, 빌드, CI 등 기존 개발 인프라가 핵심 병목으로 부상

: 기존 모노레포는 메인 브랜치 이력만 약 100GB, CI에서 하루 2,500만 건의 코드 체크아웃 발생. 기존 Git 방식으로 단순 처리할 경우 하루 600PB 이상의 데이터 트래픽이 발생할 수 있는 규모

: 이에 앤스로픽은 자체 버전 관리 시스템 Scion과 코드 리뷰 도구 Antique를 개발하고 5개월 만에 Git에서 완전히 전환. 단 7명의 엔지니어가 Claude를 활용해 구축했으며, AI 에이전트 중심의 서버 기반 아키텍처로 재설계

: Scion 도입으로 기존 Git 인프라 대비 CPU 및 메모리 요구량을 200분의 1로 축소하고, 코드 체크아웃 속도는 약 100배 개선. CI에서만 CPU 용량 25% 절감

: 개발 과정에서 Claude Mythos Preview는 기존 데이터 수집 파이프라인의 메모리 사용량을 95% 줄이고 처리 속도를 4배 개선. 엔지니어의 역할도 직접 코딩에서 시스템 설계, 제약 조건 설정, 변경 사항 검토 중심으로 전환

: 앤스로픽은 Claude Tag 기반 AI 에이전트를 시스템 모니터링에 활용하는 등 개발 프로세스 전반을 재설계. 향후 6~12개월 내 다른 기업들도 AI 코딩 확산에 따른 유사한 인프라 병목을 경험할 것으로 전망
