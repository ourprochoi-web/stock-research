Z ai, GLM-5.4 공개

: GLM-5.4는 7,500억 파라미터 규모로, 루프 트랜스포머(Loop Transformer) 아키텍처를 적용해 2조~3조 파라미터 모델에 필적하는 지능 수준을 달성했다고 설명

: 기존 GLM-5 기반 모델의 28개 레이어를 두 차례 반복 실행하는 구조. 가중치 공유를 통해 파라미터 증가 없이 연산 깊이를 확대하고, KV 캐시 공유 및 희소 어텐션 인덱스 재활용으로 추가 추론 비용을 제한

: 300억 파라미터 모델 대상 통제 실험에서 약 10%의 추가 학습 연산량만으로 수학, 과학적 추론, 장문맥 처리 성능 개선 확인. 평균 출력 길이도 10~14% 감소하며 외부 사고 토큰을 통한 추론의 일부를 모델 내부 연산으로 이전

: GLM-5.4의 생성 속도는 비혼잡 시간대 최대 200TPS, 최대 부하 시간대에도 70~80TPS 유지. 다만 지나치게 긴 사고 과정에 빠지는 한계는 여전히 존재

: 새로운 방향성으로 범용 코딩(Generalized Coding) 제시. 코딩을 다양한 작업 수행의 기반으로 활용하는 개념으로, 동영상 생성 및 편집, 로봇팔 CAD 설계, 게임 제작, 3D 모델링 등의 사례 공개

: 모델 크기와 연산 깊이를 동시에 확대하는 전략 지속. 난도가 높은 토큰에 더 많은 반복 연산을 할당하는 적응형 연산(Adaptive Compute)도 연구 중이며, 훨씬 더 큰 규모의 차세대 모델을 조만간 공개할 예정

: Z ai 채팅 및 코딩 서비스에서 이용 가능. API는 출시 예정이며, 안전성 강화 작업 완료 이후 모델 가중치도 공개할 계획
