메타 & 마이크로소프트, 내부 Claude 사용 축소

: 앤스로픽의 핵심 기업 고객인 메타와 마이크로소프트가 비용 절감과 자체 AI 제품 육성을 위해 직원들의 Claude 사용 축소

■ 메타

- 메타 Claude Code 사용자는 연초 약 6만명 → 최근 3만명으로 절반 감소. 일부는 봄철 약 10% 인력 감축 영향도 존재

- 자체 모델 기반 Muse Code, 6,000명+와 내부용 MetaCode, 3만명+ 확산. 소비자용 Muse 역시 개발 과정에서는 Claude를 사용했지만 최종 제품은 자체 모델 전환

- 비용 부담도 상당. 메타는 최근 28일간 Claude Code에 1.05억 달러 이상을 지출. 올봄 ‘tokenmaxxing’으로 사용량이 급증하자 6월부터 조직별 예산, 토큰 한도, 중앙 모니터링을 도입

■ 마이크로소프트

- 마이크로소프트도 5월 기준 내부 Claude 사용 비용이 연환산 10억 달러+에 이를 것으로 예상됐으나, 이후 Claude 사용 축소 지시로 전망치를 3분의 1 이상 하향

- GitHub Copilot 사용을 우선하고 내부 코딩의 기본 모델을 오픈AI 모델로 전환

- 특히 6만명+ 규모 Cloud & AI 조직의 직원별 AI 사용 한도를 월 10만 달러 → 1만 달러 수준 축소

- 오픈AI 모델은 마이크로소프트의 비용 부담이 낮아 내부 워크로드를 오픈AI로 전환할 경제적 유인 존재

- 다만 마이크로소프트 Copilot 투입 Claude 지출은 연환산 최소 20억 달러 수준. 가입자 증가로 계속 확대. 내부 Claude 감소를 상쇄하면서 마이크로소프트의 전체 앤스로픽 지출은 고점 대비 유지
