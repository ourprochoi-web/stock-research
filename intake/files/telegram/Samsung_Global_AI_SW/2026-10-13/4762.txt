스페이스XSI, Grok + Grok Bot + Cursor + X 통합 구독 서비스 출시

: 스페이스XSI는 Grok, Grok Bot, Cursor, X Premium을 하나의 요금제로 통합한 ‘The X Subscription’ 공식 출시. AI 챗봇, 자율형 에이전트, 코딩, 소셜미디어 기능을 단일 구독으로 제공

: 무료 요금제를 포함해 총 5개 요금제로 구성. 유료 요금제는 Plus 월 $8, Premium 월 $30, Super 월 $100, Ultra 월 $200. Plus 대비 사용량은 Premium 4배, Super 15배, Ultra 50배로 확대

: 월 $30 Premium은 기존 SuperGrok, Cursor Pro, X Premium+의 혜택을 통합. 개별 구독 시 월 $90에 해당하는 서비스를 1/3 가격에 제공한다고 강조

: Grok과 Cursor는 주간 AI 사용량 한도를 공유하는 구조. 회사 측은 모든 유료 요금제에서 자사 모델 기반 코딩 사용량이 동급 Cursor 요금제 대비 최소 2배라고 설명

: 다만 Cursor에서 GPT, Claude 등 외부 모델을 사용하는 비용은 구독료에 포함되지 않으며, API 정가 기준으로 별도 과금. 통합 사용량 혜택은 자사 Grok 모델에 적용

: 개인뿐 아니라 기업 고객도 통합 구독 가능. 팀 요금제는 개인과 동일한 인당 가격을 적용하며, 기존 Cursor Teams 대비 코딩 사용량 3배, SSO, 관리자 기능, 통합 결제 및 사용량 분석 제공

: 신규 고객은 즉시 가입할 수 있으며, 기존 SuperGrok, Cursor, X Premium 가입자는 기존 요금제를 유지하거나 통합 요금제로 전환 가능. 글로벌 서비스는 향후 며칠에 걸쳐 순차 확대 예정
