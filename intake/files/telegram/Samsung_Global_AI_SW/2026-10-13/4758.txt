메타, Muse Wonder(aka watermelon🍉) 출시

: 메타는 개인 및 업무용 AI 에이전트에 특화된 Muse Wonder와 Muse Wonder Full 공개

: GW급 Prometheus 데이터센터에서 학습한 모델로, 개인 초지능 구현을 위한 핵심 기술로 소개

: AAII 기준 Muse Wonder 52점, Wonder Full 56점 기록. 6주 전 출시된 Muse Spark 1.3(48점) 대비 각각 4점, 8점 상승. 특히 Wonder Full은 10개 평가 항목 모두에서 기존 모델 성능을 상회

: 에이전트 성능 개선이 두드러짐. Wonder Full 기준 Terminal-Bench 4.0은 33%에서 57%, GDPval-AA는 1,681에서 1,857 Elo, AA-Briefcase는 1,581에서 1,729 Elo로 상승. 전체 10개 평가 중 6개에서 상위 3위 기록하며 지식 업무와 과학적 추론에서 강점 확인

: 코딩 에이전트 성능도 크게 개선. Artificial Analysis Coding Agents Index에서 Wonder Full 68점, Wonder 63점으로 기존 Spark 1.3(54점)을 상회. Wonder Full은 Claude Sonnet 5.5(68점)와 동률이며 Opus 5.5(66점)를 앞섬

: 핵심 기술은 Active Memory와 Active Focus. Active Memory는 대화 간 사용자 맥락을 유지하고 필요한 정보를 능동적으로 검색하는 기능

: Active Focus는 장시간 작업을 지속하면서 장애물을 해결하고 새로운 정보에 맞춰 실행 계획을 조정하는 기능. 개인화된 장기 실행 에이전트 구현에 초점

: 범용성도 개선. Wonder Full은 학습 과정에서 직접 다루지 않은 새로운 작업에서도 기존 Spark 1.3보다 높은 성능을 기록

: 메타는 더 강력한 기반 모델을 활용하면서 후속학습의 성능 개선이 새로운 작업으로 효과적으로 일반화된 결과라고 설명

: 토큰 효율성은 일부 개선. 두 모델의 작업당 출력 토큰은 약 5.4만 개로 기존 대비 10% 감소. Wonder Full은 Wonder보다 입력 토큰을 16% 적게 사용하면서도 높은 성능 기록. 다만 GPT-6.1 Sol, GPT-6 Astra보다는 출력 토큰 사용량이 많은 수준

: Wonder API 가격은 입력 $4, 캐시 입력 $0.20, 출력 $20/1M 토큰. 작업당 비용은 $4.52로 GPT-6.1 Sol($0.72), Gemini 4 Argon($1.99), GPT-6 Astra($3.26)보다 높지만 Claude 주요 모델보다 낮음. Wonder Full의 API 가격은 미공개

: 두 모델 모두 100만 토큰 컨텍스트와 텍스트, 이미지, 동영상, 오디오 입력 지원. Wonder는 Meta Model API와 Muse Code에서 즉시 이용 가능하며, Wonder Full은 Muse Code 구독자에게 우선 제공. 향후 Muse 서비스에도 적용할 예정
