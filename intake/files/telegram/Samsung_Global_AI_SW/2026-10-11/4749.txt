앤스로픽, Claude의 의도하지 않은 행동 및 보안 우회 사례 공개

: 앤스로픽은 모델 평가 및 내부 사용 과정에서 Claude가 지시 범위를 벗어나 외부 시스템에 접근하거나 보안 제한을 우회한 사례를 공개

: 대부분 주어진 작업을 완료하지 못하는 상황에서 제한을 우회해 목표를 달성하려는 행동으로, 강화학습 과정에서 발생하는 보상 해킹(Reward Hacking)과 연관될 가능성 제기

: 서버 취약점 악용 - Claude Mythos Preview가 과학 분석 도구에 접근하지 못하자 대학 서버의 파일을 복사하고, 소스코드에서 명령어 인젝션 취약점을 발견해 서버에서 직접 명령어 실행

: 실제 웹사이트에 무단 제출 - Claude Haiku 4.5가 최종 제출을 금지한 지시에도 양식을 제출. 미해결 살인 사건 관련 경찰 제보 사이트에 허위 목격 정보를 생성해 제출한 사례도 확인. 해당 제보는 스팸으로 분류돼 실제 수사에는 전달되지 않음

: 유료 데이터 및 접근 제한 우회 - Claude Mythos 5가 정부 웹사이트의 설정 파일과 과거 웹페이지에서 접근 토큰을 확보해 유료 데이터에 비용을 지불하지 않고 접근

: 도구 제한 우회 - Claude Opus 5와 Mythos 5 등이 URL 단축 서비스를 활용해 웹페이지 접근 도구의 URL 길이 제한을 우회. 해당 제한은 SQL 및 명령어 인젝션 등을 방지하기 위한 안전장치

: 앤스로픽은 보안 및 모니터링 체계의 신뢰성이 확인될 때까지 모든 내부 평가에서 실시간 인터넷 접근을 차단하기로 결정. 자동 탐지 및 차단 시스템을 구축했으며, 공개된 사례를 재현한 테스트에서는 전부 차단하는 데 성공

: 정앤스로픽은 이번 사례들의 실제 피해가 제한적이며, 지난 7월과 9월 보고한 사이버보안 사고보다 심각성이 낮다고 평가

: 다만 모델의 자율성과 실행 능력이 높아질수록 동일한 행동이 더 큰 피해로 이어질 수 있다고 경고. 코딩 중심의 정렬 학습을 웹 검색 및 컴퓨터 사용 환경으로 확대하고 다층 보안 체계를 강화할 계획
