마이크로소프트, 2.8T 파라미터 자체 AI 모델 사전학습 완료

: 마이크로소프트는 자체 개발한 차세대 파운데이션 모델 MAI-Base-2의 사전학습(Pre-training)을 완료했다고 발표

: MoE 아키텍처 기반으로 전체 파라미터 2.8T, 활성 파라미터 80B 규모. 현재 후속학습(Post-training)을 진행 중이며, 차세대 MAI-Base-3 개발도 준비 중

: MAI-Base-2는 자체 평가에서 DeepSeek-V4-Pro-Base, Kimi K3, Qwen3.8 등 주요 중국 오픈웨이트 모델을 상회하는 성능 기록

: 특히 DeepSeek-V4-Pro-Base 대비 동일한 사전학습 성능을 달성하는 데 필요한 연산량(FLOPs)이 4.2~12.3배 적은 것으로 추정. 지난 6월 공개한 MAI-Base-1 대비 학습 효율도 6.3~12.7배 개선

: 학습에는 엔비디아 GB200 GPU 16,000개를 활용했으며, 2026년 8~9월 총 38일간 진행. 평균 GPU 연산 활용률(MFU)은 21%, 실제 학습 진행 시간 비율(Goodput)은 89% 기록

: 총 50T 토큰 규모의 데이터로 학습했으며, 고유 학습 데이터는 전작 대비 약 36% 확대. 별도 비전 인코더가 없는 네이티브 멀티모달 아키텍처를 도입해 이미지와 텍스트를 통합 학습. 전체 학습 토큰의 18%를 시각 데이터에 할당

: 학습 효율 개선에는 MoE 구조 최적화, Muon 옵티마이저, 학습 안정화 기술 등이 기여. 특히 MoE 레이어의 연산 활용률을 기존 24%에서 35%로 개선하며 모든 레이어에 MoE를 적용

: 마이크로소프트는 경쟁 모델의 출력을 증류하지 않고 자체 데이터 파이프라인으로 모델을 학습했다고 강조. 향후 Microsoft Foundry를 통해 파트너에게 모델 가중치를 라이선싱하고 자체 제품에도 활용할 계획
