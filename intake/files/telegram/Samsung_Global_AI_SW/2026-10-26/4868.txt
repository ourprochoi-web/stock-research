앤스로픽, Opus 5.5 출시 이후 OpenRouter 토큰 사용량 3.6배 증가

: OpenRouter 데이터에 따르면, 앤스로픽 모델의 최근 7일 평균 토큰 사용량이 Claude Opus 5.5 출시 이후 3.6배 증가. Sonnet 5.5와 Haiku 5.5 역시 긍정적인 시장 반응을 확보

: 6월부터 9월 중순까지 일평균 토큰 사용량은 약 0.5~0.8조 개 수준에서 횡보했으나, 9월 하순 Opus 5.5 출시 이후 가파르게 증가. 10월 24일 기준 일간 사용량은 약 2.8조 개까지 확대

: 특히 Opus 5.5 출시 이후 Sonnet 5.5와 Haiku 5.5가 순차적으로 출시되면서 사용량 증가세가 가속화. 기존 모델 사용량은 비교적 안정적으로 유지되는 가운데 신규 모델이 전체 토큰 사용량 확대를 주도

: 다만 OpenRouter는 제3자 API 플랫폼으로, 해당 데이터가 앤스로픽의 전체 API 사용량이나 매출 증가율을 의미하지는 않음. 토큰 사용량 증가에는 모델별 가격과 출력 토큰 비중 등의 영향도 존재
