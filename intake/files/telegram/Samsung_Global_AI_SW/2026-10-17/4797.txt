앤스로픽, AI 코딩 확산에 대응해 코드 리뷰 프로세스 재설계

: Claude가 Claude Code 자체 코드의 약 90%를 작성하는 가운데, 6~9월 병합된 PR(Pull Request)은 2배 이상 증가했지만 코드 변경 취소율(Revert Rate)은 40% 이상 감소

: AI 중심 리뷰 체계 구축 → 코드 작성 이후 Claude가 사전 검증을 수행하고, 여러 리뷰 에이전트가 병렬로 버그를 탐색. 별도 에이전트들이 발견 사항을 교차 검증해 오탐을 최소화

: 위험도 기반 인간 개입 최소화 → 저위험 변경은 자동화 검증만으로 병합 가능하며, 중위험은 1명, 고위험은 2명의 승인 필요. 사람은 아키텍처, 보안, 제품 방향 등 고차원적 판단에 집중

: 리뷰 효율성 개선 → 반복 리뷰 횟수를 제한하고 변경된 코드만 재검토하는 방식으로 개선. 1회 리뷰 및 수정 후 통과율은 65%에서 78%로 상승했으며, 평균 리뷰 횟수는 2.08회에서 1.32회로 감소

: 배포 이후 품질관리 강화 → 기능 플래그와 단계적 배포로 문제 발생 시 신속한 롤백 지원. 장애 및 코드 변경 취소 사례를 AI 리뷰어의 평가 데이터로 활용해 지속적으로 성능 개선
