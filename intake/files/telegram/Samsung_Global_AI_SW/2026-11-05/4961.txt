앤스로픽 Claude Code 제품 총괄, 오픈AI로 이직

: 앤스로픽의 Claude Code 제품 총괄(Head of Product) Cat Wu가 퇴사 후 오픈AI에 합류한다고 발표. 오픈AI에서는 Core Products의 제품 관리 조직을 총괄할 예정

: Cat Wu는 약 2년 전 Claude Code가 내부 개발 도구였던 시절부터 제품 개발에 참여. Claude Code를 업계 대표 AI 코딩 도구로 성장시키는 데 핵심적인 역할 수행

: Claude Code는 초기 코드 작성과 테스트를 지원하는 수준에서 현재 대규모 코드 마이그레이션과 신규 제품 개발까지 자율적으로 수행하는 에이전트로 발전했다고 설명

: 오픈AI에서는 티보 소티오 등과 협력해 개인과 팀의 업무를 지원하면서도 사용자가 통제권을 유지할 수 있는 AI 에이전트 개발에 집중할 계획

: Claude Code의 제품 전략과 상용화를 이끈 핵심 리더가 경쟁사로 이동했다는 점에서 주목. 오픈AI의 Codex 및 업무용 AI 에이전트 경쟁력 강화에 기여할 것으로 예상
