오픈AI, AI로 리눅스 취약점 948개 발견 및 패치 생성

: 오픈AI는 차세대 사이버 보안 모델을 활용해 취약점 발견, 검증, 악용 가능성 평가, 패치 생성을 자동화하는 파이프라인 개발. 약 $1.2M의 API 비용으로 리눅스 커널의 권한 상승 취약점 948개를 검증하고 패치 후보 생성

: 전체 커널 코드의 약 7%인 280만 줄을 분석해 잠재적 취약점 2,308개 발견. 이 중 1,724개(75%)를 실제 재현했으며, 정보 유출 PoC 291개와 작동하는 권한 상승 익스플로잇 1,169개 개발. 중복을 제거한 고유 취약점은 948개

: 고유 취약점당 평균 비용은 $1,279로, 7월 GPT-5.6 Sol 실험 당시 $3,094 대비 약 59% 감소. 발견한 취약점도 166개에서 948개로 약 5.7배 증가. 모델 성능 향상에 따른 보안 연구 생산성 개선 확인

: 기존 버그 바운티 보상금 기준으로 948개 취약점의 가상 가치는 $18.9M~$66.3M으로, 연구 비용의 16~55배 수준. 에이전트는 기존에 알려지지 않은 새로운 공격 기법도 최소 10개 발견

: AI의 취약점 발견 능력이 빠르게 향상되면서 자동화된 패치 생성이 필수적이라고 강조. 향후 프런티어 모델이 대부분의 잠재적 취약점을 발견할 수 있을 것으로 전망하며, 공격과 방어 양측의 AI 활용 확대 가능성 시사
