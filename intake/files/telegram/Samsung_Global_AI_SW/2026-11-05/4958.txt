오픈AI, Images 2.6 공개. 이미지 생성 속도 50% 개선 및 GIF 생성 지원

: 오픈AI는 ChatGPT, Codex, API에 새로운 이미지 생성 모델 Images 2.6 출시. 현재 플랫폼 전반의 이미지 생성량은 주간 40억 개, 일평균 5억 개 이상으로 확대

: 기존 대비 이미지 생성 속도 50% 개선. API에서는 속도 중심의 Flare와 고품질 중심의 Sunburst 제공. Flare는 최저 품질 설정 시 최소 6초 만에 이미지 생성 가능

: GIF 애니메이션 생성 기능 신규 도입. 단일 프롬프트로 정적인 이미지나 캐릭터를 움직이는 GIF로 제작할 수 있어 마케팅, 소셜미디어, 콘텐츠 제작 등에 활용 가능

: 이미지 편집 과정에서 캐릭터, 제품, 브랜드의 일관성 유지 능력 강화. 기존 ChatGPT에서 제공하던 특정 영역 편집 기능을 API로 확대하고 SVG 내보내기 기능 추가

: 개발자가 이미지 생성 및 편집에 투입되는 처리 수준을 조절할 수 있는 Complexity 매개변수 도입. Images 2.6은 전 세계 모든 ChatGPT 및 Codex 구독 요금제에서 제공
