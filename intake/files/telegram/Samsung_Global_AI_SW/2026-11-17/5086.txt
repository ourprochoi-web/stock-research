OpenRouter, 앤스로픽 Fable 5.2 출시 첫 주 지출 비중 11% 기록

: 앤스로픽의 최신 모델 Fable 5.2는 출시 후 첫 1주일 동안 앤스로픽 모델 전체 API 지출액의 11%를 차지. 토큰 사용량 기준 점유율은 5%

: 이는 이전 모델인 Fable 5.1(12%), Fable 5(13%)의 출시 첫 주 지출 비중과 유사한 수준으로, 신모델 초기 채택률은 전작과 큰 차이가 없는 것으로 나타남

: 반면 Opus 5.5는 앤스로픽 모델 전체 지출액의 46%를 차지하며 여전히 가장 높은 비중을 유지

: Fable 5.2가 기존 Fable 시리즈와 마찬가지로 일상적으로 사용하는 모델보다는 고성능이 필요한 특정 작업에 선택적으로 활용되는 모델로 자리 잡았다고 평가

: 다만 해당 수치는 오픈라우터 플랫폼 내 앤스로픽 모델 간 지출 비중으로, 앤스로픽 전체 API 매출이나 실제 이용량을 대표하지는 않음
