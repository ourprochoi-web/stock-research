오픈AI, COBOL 등 레거시 프로그래밍 언어 코딩 성능 대폭 개선

: 오픈AI가 COBOL, Fortran, Visual Basic 등 학습 데이터가 부족한 프로그래밍 언어에서 최신 모델의 소프트웨어 개발 및 마이그레이션 성능 개선 결과 발표

: 자체 개발한 MultiLangBench에서 GPT-6 Astra의 평균 테스트 통과율은 87.4%로 GPT-5.6 Sol(26.8%) 대비 대폭 상승. 20개 언어 모두에서 성능 개선

: GPT-6 Luna 역시 평균 40.3%를 기록하며 GPT-5.6 Sol을 상회. 샘플당 API 비용은 $0.77로 기존 $3.48 대비 78% 절감

: COBOL 코드를 C++, Java, Python 등으로 변환하는 마이그레이션 평가에서 GPT-6.1 Sol의 정확도는 86.6%(vs GPT-5.6 Sol 5.4%). API 비용은 39% 낮았으며, 추론 강도를 높이면 정확도 97.9% 달성
