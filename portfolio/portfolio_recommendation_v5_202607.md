**v4→v5 분산 개선:** 독립 클러스터 7개→**8개**. K-뷰티(H)는 기존 어떤 클러스터와도 상관관계가 낮음:
- 방산/조선(지정학) vs K-뷰티(소비재/수출) → 무관
- HBM/AI(기술투자) vs K-뷰티(뷰티소비) → 무관
- 전력/ESS(인프라) vs K-뷰티 → 무관
- GLP-1(의약품) vs K-뷰티 → 약한 상관 (파마리서치만 바이오 연결)

## 11. 4인 토론 결과 요약 + K-뷰티 추가 판단

본 포트폴리오(v3)는 4명의 에이전트(강세론자, 약세론자, 매크로 전략가, 역발상 투자자)가 검토. v5에서 K-뷰티 편입은 추가 분석 기반:

**v5 K-뷰티 편입 근거:**
- **구조적 성장:** 수출 $7.6B(2020)→$13B+(2026E), CAGR +10%
- **탈중국 완성:** 대중국 비중 53%→18%, 미국 1위 수출 대상국 부상
- **독립 클러스터:** 기존 7개와 상관관계 거의 없음 → 분산 극대화
- **밸류에이션:** 실리콘투 PEG 0.31은 전체 포트에서 네이버(0.18), 현대로템(0.29) 다음 3위
- **리서치 기반:** K-뷰티 섹터 종합 + 에이피알/파마리서치/실리콘투 심층 3편 + 인디/ODM 2편 = 총 8편 리서치 완료

**K-뷰티 편입 시 유의 사항:**
- 코스닥 비중 증가 (0%→6%) — 금융기관 내부 기준 확인 필요
- 인디뷰티 트렌드 전환 리스크 — 소비재 특성상 사이클 존재
- 환율 민감도 — K-뷰티 수출은 원화 약세 수혜 / 강세 시 역풍
