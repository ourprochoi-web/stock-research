## 1. 투자 프레임워크 — 4-Factor 비대칭 (v7 유지)

> v7 Section 1 참조. 4-Factor 체계(구조적 수요 × 밸류체인 포지션 × 미스프라이싱 × 촉매) 유지. v8에서는 **촉매(Factor 4) 재평가**에 집중 — 방산 촉매 약화, K-뷰티 촉매 강화가 핵심 변동.

```
┌──────────────────────────────────────────────────────┐
│  Factor 1. 구조적 수요 — 5년 후에도 커지는가?          │  v8: 전 섹터 유효
├──────────────────────────────────────────────────────┤
│  Factor 2. 밸류체인 — 대체 불가능한가?                 │  v8: 전 섹터 유효
├──────────────────────────────────────────────────────┤
│  Factor 3. 미스프라이싱 — 시장이 뭘 틀렸는가?          │  v8: 반도체 미스프라이싱 심화
├──────────────────────────────────────────────────────┤
│  Factor 4. 촉매 — 갭이 닫히는 이벤트와 시점은?         │  ★ v8 핵심: 방산↓ K-뷰티↑
└──────────────────────────────────────────────────────┘
```
