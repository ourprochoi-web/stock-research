## 1. 투자 프레임워크 — 4-Factor 비대칭 (★ v7 핵심)

### 1-1. PE/PEG에서 4-Factor로 전환한 이유

v6까지는 Fwd PER, PEG, 컨센서스 TP를 핵심 지표로 사용했다. 그러나 이 접근에는 구조적 한계가 있다:

| PE/PEG의 한계 | 설명 | 실제 사례 |
|-------------|------|----------|
| **역사적 비교 불가** | 산업 구조가 바뀌면 과거 PE 밴드가 무의미 | 한화에어로 PER 33x는 방산 수주잔고 39.7조(자체, 그룹 합산 116.8조) 이전에는 존재하지 않던 밸류에이션 |
| **밸류체인 위치 무시** | PE가 같아도 대체 가능성이 다르면 리스크가 다름 | SK하이닉스(HBM 독점)와 일반 DRAM 업체의 PER 5x는 의미가 다름 |
| **촉매 시점 무시** | "싸다"와 "언제 오르나"는 다른 질문 | Novo PE 12.8x이지만 CagriSema 결과는 10월 |
| **시장 오류 미식별** | PE만으로는 시장이 뭘 잘못 봤는지 알 수 없음 | 한국 VKOSPI 87.91은 펀더멘털이 아니라 반대매매 구조 문제 |

### 1-2. 4-Factor 체계

모든 투자 판단에 4가지 질문을 던진다:

```
┌──────────────────────────────────────────────────────┐
│  Factor 1. 구조적 수요 (Structural Demand)            │
│  → 이 시장은 5년 후에도 커지는가?                      │
│  → 일시적 트렌드인가, 구조적 전환인가?                  │
├──────────────────────────────────────────────────────┤
│  Factor 2. 밸류체인 포지션 (Value Chain Position)      │
│  → 이 회사는 대체 불가능한가?                          │
│  → 가격 결정력이 있는가? 경쟁자 진입이 가능한가?        │
├──────────────────────────────────────────────────────┤
│  Factor 3. 미스프라이싱 (Mispricing)                   │
│  → 시장이 구체적으로 뭘 틀렸는가?                      │
│  → PE/PEG는 여기서 보조 지표로만 사용                   │
├──────────────────────────────────────────────────────┤
│  Factor 4. 촉매 (Catalyst)                            │
│  → 이 갭이 닫히는 구체적 이벤트와 시점은?               │
│  → 촉매 없는 저평가는 "밸류 트랩"                       │
└──────────────────────────────────────────────────────┘
```

### 1-3. 비대칭 수익률 분석

**투자 우선순위 = 비대칭 비율(Bull ÷ Bear) × 촉매 확실성**

| 순위 | 종목 | Bull Case | Bear Case | **비대칭 비율** | 촉매 확실성 | 최종 판단 |
|------|------|-----------|-----------|----------------|-----------|----------|
| **1** | **한화에어로** | +96% (TP 1,707K) | -20% (수출 지연) | **4.8 : 1** | ★★★★ (수주잔고 39.7조, 3중 호재) | **Phase 1 최우선** |
| **2** | **현대로템** | +89% (TP 312K) | -18% (폴란드 지연) | **2.9 : 1** | ★★★★ (K2 3차 210대) | **Phase 1** |
| **3** | **실리콘투** | +59% (TP 54K) | -20% (관세 리스크) | **2.9 : 1** | ★★★☆ (수출 독립) | **Phase 1** |
| **4** | **SK하이닉스** | +43% (TP 2,736K) | -17% (ASP 하락) | **2.6 : 1** | ★★★ (AI CAPEX) | **보유 중 + Phase 3 추가** |
| **5** | **MSFT/테크** | +28% (PE 정상화) | -12% (성장 둔화) | **2.3 : 1** | ★★★ (7/29 실적) | **Phase 2 (ETF 경유)** |

> **비대칭 비율이 투자 순서를 결정한다.** PE가 가장 낮은 SK하이닉스(5.3x)가 아니라, 비대칭이 가장 큰 한화에어로(4.8:1)가 최우선이다.
