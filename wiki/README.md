# 배경 지식 위키 (wiki/)

**목적:** 산업사 · 기술 원리 · 특허·규제 역사 · 공급망 구조 · 데이터 시계열 이력. 
**넣지 않는 것:** 스탠스 · 테제 · 장부 · 매매 의견. 판단은 `brain/` · `intake/routing.jsonl` · `ledger/` 가 정본.

## 규칙
- 한 주제 = 한 페이지, 한국어, kebab-case 파일명 (`wiki/<영역>/<주제>.md`).
- 모든 사실 줄: `날짜 · 출처(경로/URL) · 등급` — 등급: **A** 공시·1차자료 / **B** 증권사·언론 / **C** 출연자·게시자 주장(미검증) / **ASR** 자동자막 기반.
- **append-only, 날짜순.** 고치지 않고 정정 줄을 아래에 덧붙인다.
- 상단 `related:` 에 관련 brain thesis/entity 키(예: `entity:LGES`, `memory_cycle#T1`).

## 패킷 → 위키 덧붙이기 절차
1. 패킷(유튜브 daily · 텔레그램 `pull_*_new.md` · X `packets/*-lead.txt`)을 읽는다.
2. 판단에 닿는 내용 → 기존대로 routing. 배경 지식(역사·원리·구조·수치 이력) → 위키.
3. `wiki/index.md` 에서 맞는 페이지를 찾고, 없으면 새 페이지 + index 한 줄.
4. 페이지 끝(또는 시계열 표 맨 아래)에 `날짜 · 출처 · 등급 · 내용` 을 원문에 충실히 추가. 주장은 「(주장)」 표기.
5. 숫자 시계열은 표에 행 추가(날짜·출처·추정치·비고). 이전 행은 지우지 않는다.
